# Корочки.есть — реализованная версия

## Установка
1. Установите Node.js 22+ и PostgreSQL.
2. Скопируйте `.env.example` в `.env`.
3. Поднимите БД:
   `docker run -p 5431:5432 -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=demo --name=demo postgres:18`
4. `npm install`
5. `npm run db:generate`
6. `npm run db:push`
7. `npm run db:seed`
8. `npm run dev`

## Администратор
Логин `Admin`, пароль `KorokNET`. Роль ADMIN присваивается seed-ом.

## Реализовано
- Регистрация с проверкой логина, пароля, ФИО, телефона и email; логин уникален.
- Пароли хешируются scrypt, cookie-сессия HttpOnly.
- Авторизация и выход.
- Создание заявки с курсом, датой, способом оплаты.
- Личный кабинет: пользователь видит только свои заявки.
- Отзыв разрешен сервером только для завершенной заявки, один отзыв на заявку.
- Админ-панель: список заявок, поиск/фильтр, изменение статусов.
- Главная с автоматическим слайдером (3 секунды) и стрелками.
- Адаптивный интерфейс для мобильного экрана.
- Prisma модели User, Entry, Review.

## ER-диаграмма
В Prisma схема задает связи User 1—N Entry, User 1—N Review и Entry 1—0..1 Review. Для визуальной ER-диаграммы в pgAdmin: Tools → ERD Tool → Add tables (User, Entry, Review) → Save/Export.

## Проверка
В этой среде `npm install` не завершился в доступное время, поэтому сборка и подключение к PostgreSQL здесь не подтверждены. Выполните команды установки и сборки локально; при ошибках пришлите лог.
